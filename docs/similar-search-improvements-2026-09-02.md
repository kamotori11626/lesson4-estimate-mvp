# 類似案件検索・名寄せ支援 Step 4改善実装記録

実施日：2026-09-02

## 実装した4点

1. **過去見積金額の定義を明示**
   - `18_過去見積履歴.csv`には`quote_price`の列しかなく、単価／総額、通貨、税区分の定義がない。
   - 画面では`quote_price`原値を「過去見積金額」として表示し、金額種別・通貨・税区分が未定義であることを併記する。
   - 原本にない「円単価」等は推測しない。

2. **名寄せ候補の初期表示を要約**
   - 代表レコード、一致理由、注意事項だけを常時表示する。
   - 最大20行程度ある全マスタ行は「詳細を表示」の開閉式にした。

3. **今回の加工種別を検索条件に追加**
   - 任意入力の「加工種別」欄を追加した。
   - 今回値と過去値が一致するとき10点を付与する。入力がないときは推測せず0点とし、技術確認が必要と表示する。
   - 合計0〜100点を維持するため、論理品番40点、顧客20点、材質15点、数量最大10点、加工種別10点、新しさ最大5点へ更新した。

4. **過去見積金額のばらつき警告（旧仕様）**
   - この時点では、表示候補に正の`quote_price`が2件以上ある場合に最大／最小比を計算し、1.5倍以上なら警告する仕様であった。
   - その後、教材の価格差異イベントを踏まえ、比較可能条件、最新見積を基準とする差率、10%／20%／30%の段階、重要注記による繰上げ、人間の対応責任を含む`price-difference-rules-1.0`へ置き換えた。現行仕様は`price-difference-event-design-2026-09-02.md`を正とする。
