## 発見した不具合と次の対応

対象は src/extraction-store.mjs のsaveReview内、extraction_review_drafts.changesへの保存。JavaScript配列をJSONとして文字列化せず、そのままDBドライバーに渡している。使用中のpgドライバーは配列をPostgreSQLの配列表現に変換するため、空配列が{}としてJSON列に入った。

さらに、データを書き換えない SELECT $1::jsonb に変更1件の配列を同じ方法で渡すと、22P02（invalid input syntax for type json）を再現した。これは修正値を伴う保存に失敗するリスクを示す。ただし、今回のChrome操作では値変更を伴う保存までは実施していないため、その画面上の挙動は未検証。

次に必要なのはJSON配列として保存する処理の修正と、実際に値を変更した下書きの保存・履歴・再表示の再検証。この検証にも実Gemini送信は不要。今回の依頼は確認のため、通常アプリへの修正は行っていない。
